## Compiler and commands
Programs are written for C++17. Compile a task with:
```bash
g++ -std=c++17 -Wall -Wextra -pedantic Task01/task01.cpp -o task01
```
Run on Linux/macOS:
```bash
./task01
```
Run on Windows PowerShell:
```powershell
g++ -std=c++17 -Wall -Wextra -pedantic Task01/task01.cpp -o task01.exe
.\task01.exe
```
Record your actual compiler version using `g++ --version`.
